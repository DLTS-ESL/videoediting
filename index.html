How it works

✓ Choose a Chrome tab

Use the sharing picker to select the tab playing the video.

✓ Capture supported audio

Select tab audio in Chrome's picker when available. Audio capture depends on the browser and source.

✓ Save the recording

Preview and download the captured file locally.

! MP4 is not guaranteed

If MP4 recording is unsupported, the downloaded file will be WebM. The extension will match the actual file format.

Browser requirements

Use a current version of Chrome and open this page through HTTPS, such as GitHub Pages. Allow screen sharing when prompted.
